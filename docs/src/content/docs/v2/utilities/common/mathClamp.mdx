The **`mathClamp`** function Clamps a number to be within a specified range

## Usage
```ts
import { mathClamp } from '@mustib/utils'

mathClamp(1,2,3) // 2
mathClamp(2,1,3) // 2
mathClamp(1,3,2) // 2
```

## Definition
```ts
function mathClamp(
  minValue: number,
  currentValue: number,
  maxValue: number
): number
```
